# Contributing to the AMS Card

Thanks for your interest in the Agent Memory System Card (AMS Card).

## Preferred feedback channel

Most feedback should go through the public [feedback form](https://forms.gle/TC8JLYi8YTZrmiDF9). The same questions are listed in [`feedback-questionnaire.md`](feedback-questionnaire.md).

Use the form for structured responses about scope, terminology, missing sections, adoption barriers, privacy and governance coverage, and how well the template fits real systems.

## GitHub Issues

You may [open an issue](https://github.com/mila-iqia/agent-memory-system-card/issues/new/choose) for a concrete problem or suggestion that is easier to track in the repository — for example a typo, a broken link, an unclear section, or a specific gap you want maintainers to see.

Please:

- Search existing issues first
- Use one topic per issue
- Point to the relevant file or section when you can
- Prefer the feedback form when you are answering the questionnaire

## Pull requests

We are not accepting pull requests from external collaborators at this time. If you have a proposed change, open an issue (or use the form) and describe the problem and suggested fix. Maintainers will update the repository when appropriate.

## Code of Conduct

Participation in this project is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
