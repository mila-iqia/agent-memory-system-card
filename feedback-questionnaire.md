# Memory System Card — Feedback

Thanks for looking at the [Agent Memory Card](https://github.com/mila-iqia/agent-memory-card).
This short form helps us improve the template.
Responses are reviewed by the Mila team.

   - Other: ________

## Current state

4. **Do you use agent memory today?**  
   Tell us whether and how you use memory with agents — including production systems, prototypes, evaluations, personal setups, or publicly available tools. If you do not use agent memory yet, say so.  
   Paragraph, required.

5. **What are you using memory for?**  
   Use-case discovery: what jobs or workflows memory supports for you.  
   Paragraph, optional.
